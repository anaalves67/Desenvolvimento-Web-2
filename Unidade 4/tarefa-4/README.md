# API de Receitas Culinárias

## Tema da API

Esta API REST fornece um catálogo de receitas culinárias e comidas típicas regionais, contendo informações sobre categoria do prato, tempo de preparo (em minutos) e rendimento em porções.

## Como instalar e rodar

No terminal, dentro da pasta do projeto (`Unidade 4/tarefa-4`), execute os comandos abaixo:

```bash
# 1. Instalar as dependências do projeto (Express)
npm install

# 2. Iniciar o servidor na porta 3000
node index.js
```
